  TOP 6 FAILURE SCENARIOS & FIXES
═══════════════════════════════════════════════════════════════════════════════

  1. KB search returns 0 hits
     → Check DocsV2 schema, re-seed corpus

  2. Router always routes to LLM
     → Lower RAG_PROBE_THRESHOLD (0.65 → 0.55)

  3. Latency > 300ms
     → Check Weaviate cache, tune top_k

  4. Canary fails gates
     → make canary-rollback, check logs, fix, retest

  5. Metrics not collecting
     → Restart unified-metrics service

  6. Stream errors in adapter
     → Check nginx buffering, increase timeouts
