## 🚀 Deployment Checklist

### Required Configuration

#### GitHub Secrets
```yaml
GITHUB_TOKEN: your-personal-access-token
GITHUB_REPO: yourorg/yourrepo
SLACK_WEBHOOK_URL: https://hooks.slack.com/services/...
SLACK_SIGNING_SECRET: your-slack-signing-secret
GRAFANA_URL: https://your-grafana.com
GRAFANA_TOKEN: your-grafana-api-token
PROM_URL: http://your-prometheus:9090
DEPLOY_HOST: your-server.com (optional for SSH deploy)
DEPLOY_USER: deploy-user (optional)
DEPLOY_SSH_KEY: your-ssh-key (optional)
```

#### Server Configuration
```bash
# Environment variables
export COMPOSE_FILE=docker-compose.athena-governance.yml
export PROM_URL=http://localhost:9090
export GRAFANA_URL=https://grafana.your-domain.com

# Cron jobs
0 0 * * * /path/to/scripts/rotate_audit.sh  # Daily log rotation
0 1 * * 1 rclone copy logs/archive s3:governance-audit/$(date +%Y-%U)/ --checksum  # Weekly S3 backup
```

#### Makefile Commands
```bash
# Core Operations
make governance-up              # Start all governance services
make governance-gate            # Run pre-deploy health check
make governance-deploy          # Full deploy with gates
make governance-rollback        # Emergency rollback

# Canary Operations
make governance-canary-watch    # Run canary analysis
make governance-promote         # Manual promote
make governance-tune-windows    # Optimize canary windows
make governance-windows-show    # Show current window settings

# Learning & Adaptation
make governance-adaptive-thresholds  # Learn optimal thresholds
make governance-thresholds-show      # Show learned thresholds

# Predictive Intelligence
make governance-predict         # Predict rollback probability
make governance-insights        # Get predictive insights
```

### Slack App Setup
1. Create Slack app at https://api.slack.com/apps
2. Add slash commands: `/governance-status`, `/governance-force-promote`, `/governance-force-rollback`, `/governance-override`
3. Set request URL to `https://your-domain.com/slack/governance`
4. Install to workspace and invite to governance channels
5. Copy signing secret to `SLACK_SIGNING_SECRET`

### Grafana Dashboard Setup
1. Access Grafana at `http://localhost:3001`
2. Import dashboards from `monitoring/grafana/dashboards/`
3. Configure Prometheus data source
4. Create API token with annotation permissions
5. Set `GRAFANA_URL` and `GRAFANA_TOKEN`
