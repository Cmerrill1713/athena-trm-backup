# TRM - Tiny Recursive Models

## What is TRM?

**TRM stands for Tiny Recursive Model.**

Tiny Recursive Models are lightweight, efficient AI models designed for local execution with minimal resource requirements. They are optimized for edge computing and privacy-focused deployments.

## Key Characteristics:

- **Tiny:** Small parameter count for fast inference
- **Recursive:** Self-improving through iterative refinement
- **Local-First:** Designed to run without cloud dependencies
- **Efficient:** Optimized for CPU/GPU efficiency

## Use Cases:

- Local AI assistants
- Edge computing applications
- Privacy-sensitive deployments
- Resource-constrained environments
- Offline AI capabilities

## Integration with Athena:

TRM models are part of the Athena ecosystem, integrated through:

- MLX framework for Apple Silicon optimization
- Ollama for model serving
- Local-first routing architecture
- Governance system oversight
