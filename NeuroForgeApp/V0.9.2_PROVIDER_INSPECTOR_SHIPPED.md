## 🚀 How It Works

### **User Experience:**
```
1. Launch app with QA_MODE=1
2. Inspector appears in bottom-right corner
3. Select provider: Auto / FastVLM / Ollama / TRM
4. See real-time health indicators (🟢/🔴)
5. View latency metrics for each provider
6. Toggle visibility with ⌘⌥I
7. Reset to auto with ⌘⇧0
8. Refresh health with ⌘⇧R
9. Selection persists across app launches
```

### **Technical Flow:**
```
User selects provider
    ↓
ProviderOverrideManager.set(provider)
    ↓
Persist to UserDefaults
    ↓
Try POST /api/router/override (optional)
    ↓
On next chat request:
    ↓
NetworkInterceptor.injectProviderHeader()
    ↓
Add X-Provider-Override: fastvlm header
    ↓
Backend router respects override
    ↓
Response routed through selected provider
```
