## 🎯 Complete User Flow

### Chat → Low Confidence → Auto Ops
```
1. User: "logs?" (vague)
2. Athena: 18% confidence
3. Ops window auto-opens
4. Toast: "Ops window opened (low confidence)"
5. Ops shows: Event log with timestamp
6. User sees: Why confidence was low
```
