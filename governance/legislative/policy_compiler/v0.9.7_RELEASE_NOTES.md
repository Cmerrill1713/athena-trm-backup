## 📋 **Migration Guide**

### **Upgrading from v0.9.6**

1. **Pull latest code**
   ```bash
   git fetch --tags
   git checkout v0.9.7
   ```

2. **Install UV (if not already installed)**
   ```bash
   pip install uv
   ```

3. **Set up services**
   ```bash
   # Create UV venv
   uv venv .uv-services --python 3.9

   # Install dependencies
   uv pip install fastapi uvicorn pydantic prometheus-client requests numpy Pillow
   ```

4. **Start platform**
   ```bash
   make stack-full
   ```

5. **Verify platform**
   ```bash
   make verify
   ```

### **New Environment Variables**
```bash
# Optional
BRIDGE_TOKEN=<your-token>           # For authenticated requests
WEAVIATE_URL=http://localhost:8080 # Vector database
RAG_FALLBACK_MODE=true              # Enable graceful degradation
VISION_ROUTER_URL=http://localhost:8811/v1/vision  # FastVLM endpoint
```

## 🐛 **Known Issues & Workarounds**

### **Minor Items**
1. **MCP Port Conflict**
   - **Issue**: MCP Orchestration and Weaviate both on port 8080
   - **Workaround**: MCP Orchestration can use port 8084
   - **Impact**: Minimal (services don't conflict in practice)

2. **UAT Health Endpoint**
   - **Issue**: UAT exposes `/health`, validator tries `/ready` then `/health`
   - **Solution**: Validator already patched to handle both
   - **Impact**: None

3. **Weaviate Authentication**
   - **Issue**: Weaviate requires token on port 8080
   - **Solution**: RAG fallback mode enabled
   - **Impact**: None (graceful degradation)
