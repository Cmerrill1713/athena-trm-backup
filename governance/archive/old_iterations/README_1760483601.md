## 🚀 Three-SDK Integration

### 1. **Pydantic AI SDK** - Orchestration Layer
**Role:** Master coordinator that can use ALL tools

```python
from pydantic_ai import Agent
from pydantic_ai.mcp import MCPServerStdio

orchestrator = Agent('openai:gpt-4', mcp_servers=[...])
result = await orchestrator.run(
    "Get YouTube transcript, research on arXiv, and summarize findings"
)
```

### 2. **FastMCP** - Python Tool Servers
**Role:** Specialized Python-based tools

```python
from mcp.server.fastmcp import FastMCP, tool

youtube_mcp = FastMCP("youtube")

@tool()
def get_transcript(url: str):
    from yt_dlp_transcript import yt_dlp_transcript
    return yt_dlp_transcript(url)
```

### 3. **Node.js MCP SDK** - JavaScript Tools
**Role:** JavaScript/TypeScript tools and integrations

```javascript
const server = new Server({ name: 'node-tools', version: '1.0.0' });
// Handles web scraping, API calls, etc.
```

## 📝 Usage Examples

### Example 1: YouTube + Research Pipeline

```python
from pydantic_ai import Agent
from pydantic_ai.mcp import MCPServerStdio

# Create agent with ecosystem access
agent = Agent(
    'openai:gpt-4',
    mcp_servers=[
        MCPServerStdio(
            command='docker',
            args=['exec', '-i', 'mcp-ecosystem', 'python', '/mcp/pydantic_orchestrator.py']
        )
    ]
)

# Agent can orchestrate complex workflows
result = await agent.run(
    """
    1. Get transcript from https://youtube.com/watch?v=VIDEO_ID
    2. Search arXiv for related papers
    3. Summarize findings and store in MCP Store
    """
)
```

### Example 2: Direct Tool Access

```python
from mcp import Client

mcp = Client()

# Use YouTube tool
transcript = mcp.call_tool("youtube:get_transcript",
    url="https://youtube.com/watch?v=..."
)

# Use research tool
papers = mcp.call_tool("research:search_arxiv",
    query="quantum computing"
)

# Use web tool
search = mcp.call_tool("web:search_duckduckgo",
    query="MCP protocol"
)

# Store result
mcp.call_tool("store:write_result",
    agent="user",
    service="research-pipeline",
    status="PASS",
    summary="Completed research"
)
```

### Example 3: Cross-SDK Workflow

```bash
# Node.js tool: Test a service
docker exec -i mcp-ecosystem node /mcp/node_servers/index.js <<EOF
{"method": "tools/call", "params": {"name": "test_service", "arguments": {"url": "http://localhost:8014/health"}}}
EOF

# Python tool: Get transcript
docker exec -i mcp-ecosystem python /mcp/python_servers/youtube_server.py <<EOF
{"method": "tools/call", "params": {"name": "get_transcript", "arguments": {"url": "..."}}}
EOF

# Pydantic AI: Orchestrate both
docker exec -i mcp-ecosystem python /mcp/pydantic_orchestrator.py <<EOF
Test the bridge service, then fetch a YouTube transcript about it
EOF
```
