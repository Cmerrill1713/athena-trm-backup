# 🚀 FastVLM - Production-Ready Vision AI

**Apple's vision-language model integrated into Athena with enterprise-grade infrastructure**

---

## ⚡ Quick Start (5 Minutes)

```bash
cd /Users/christianmerrill/Documents/GitHub
make fastvlm-go-live
```

**That's it!** The script will:
1. Start monitoring (Prometheus + Grafana)
2. Download model (~2GB, first time only)
3. Start FastVLM server with warmup
4. Run validation tests
5. Offer to enable 24/7 automation

## 📊 Commands

### **Daily Operations** (90 seconds)
```bash

```

### **Use Vision**
```bash
make vision-chart IMG=chart.png      # Extract data
make vision-ocr IMG=document.png     # Extract text
make vision-ui IMG=screenshot.png    # Analyze UI
```

### **Monitor**
```bash
make fastvlm-health                  # Health check
make fastvlm-metrics                 # View metrics
make lineage-tree                    # Model history
```
