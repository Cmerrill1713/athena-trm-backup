## 🛠️ **COMMAND REFERENCE**

### **Primary Interfaces**
```bash
# Conversational AI
athena                    # Natural language chat
athena-brief             # Quick status briefing

# Voice Control
athena-wake              # Wake-word listening
athena-voice --mode voice # Voice-only conversation

# Operations Dashboard
ai-ops                   # Interactive CLI dashboard
ai-check                 # Quick health check

# System Management
athena-maintenance status # Maintenance status
athena-maintenance run   # Manual maintenance

# Alert System
athena-alerts stats      # Alert statistics
athena-alerts test       # Test all channels
```

### **Configuration Commands**
```bash
# Sensitivity Tuning
athena-sens-low          # Quiet environments
athena-sens-med          # Balanced (default)
athena-sens-high         # Noisy environments

# Service Management
sudo systemctl start athena-wake-word          # Enable wake-word
sudo systemctl start athena-memory-maintenance.timer  # Enable maintenance
sudo systemctl start athena-scheduler         # Enable briefings
```
